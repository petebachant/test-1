# Don't edit anything here

Calkit writes this folder from the project, for the documents
beside it to include with `\ckvalue`, `\ckfigure`,
`\cktable`, and `\ckinclude`. It's rewritten whenever the
pipeline runs or is checked and on every Overleaf sync, so edits
here are lost and never reach the project.
To change a value, figure, or table, change where it comes from.
